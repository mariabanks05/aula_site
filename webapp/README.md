Aplicação Web Mobile-First

Esta pasta contém uma aplicação web simples, mobile-first, sem React ou Expo.

Como usar:

1. Abra `webapp/index.html` em um navegador.
2. Edite `webapp/styles.css` e `webapp/app.js` para ajustar o layout e as ações.

Funcionalidade inicial:
- Barra de busca no cardápio
- Navegação entre Buscar / Pedidos / Perfil
- Lista de itens de exemplo com preço e botão de adicionar
