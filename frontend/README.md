Front-end (Expo) — Instruções iniciais

1. Instalar o Expo CLI (global) e dependências do projeto:

```bash
npm install -g expo-cli
cd frontend
npm install
```

2. Executar o app em modo de desenvolvimento:

```bash
npm run start
```

Observações:
- Este scaffold é mínimo: instale `@react-navigation/native` e dependências nativas conforme a documentação de react-navigation.
- Configurar Firebase e outras integrações posteriormente.
