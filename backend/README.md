Backend — Placeholders e instruções

Este diretório conterá configurações relacionadas ao backend e integrações (Firebase).

Sugestões iniciais:
- `firebaseConfig.js`: arquivo com as credenciais do projeto Firebase (use variáveis de ambiente, não commit).
- `firestore.rules`: regras de segurança do Firestore.
- Implementar funções Cloud Functions se precisar de confirmações automáticas de pagamento.
